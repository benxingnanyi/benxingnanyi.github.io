这是这个博客的第一篇文章，先简单交代一下我是谁、这个博客打算写什么。

我是许仲昊，做 Java 后端 GIS 开发，日常和 PostGIS、JTS 打交道，处理道路几何检查、空间数据质量这类问题。

最近我定下了一个方向：往 AI Agent 开发转，并且在 Python 和 Go 之间做了单选，选了 Python。理由不复杂：Agent 的生态和岗位都在 Python 这边现成存在，而我最值钱的经验——空间数据处理——在 Python 里有 Shapely 这样和 JTS 一脉相承的库，能直接带走。

第一步已经定好：把我现在工作中做的道路宽度异常检查，用 Python + Shapely 重写成一个工具函数，再接上大模型的工具调用，让它能听懂一句中文问题、自己选工具、返回真实算出来的异常路段。

后续这个博客会记录三类东西：GIS 开发实践、AI Agent 学习过程、胶片摄影。更新随缘，但会认真写。
